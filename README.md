# 🎯 定時多點依序連點器 (Scheduled Multi-Point Auto Clicker)

專為 Android 手機設計的免 Root **定時多點依序自動連點器**。支援設定精準觸發時刻（精確至 `0.1` 秒 `HH:mm:ss.S`，並整合 NTP 台灣標準時間校準），時間一到自動依照 `#1 → #2 → #3...` 順序在指定位置點選指定次數！

## ✨ 核心功能

1. **多點編號準星自由拖曳 (`#1`, `#2`, `#3`...)**
   - 懸浮面板可隨時一鍵 `➕點` 新增準星或 `➖點` 減少準星。
   - 每個準星皆可自由拖曳至目標按鈕位置，準星中心紅點即為精準點擊落點。
2. **自訂每個點位點選次數 & 整組循環輪數**
   - 可設定**每個點位各自要連點幾次**（在主畫面設定，或直接「單擊準星」快速切換 `1次 / 2次 / 3次 / 5次 / 10次`）。
   - 可設定**整組順序 (`#1 → #2 → #3`) 總共循環幾輪**，以及同點連點間隔 (ms)、切換下一點位間隔 (ms)。
3. **指定時刻自動觸發 (`HH:mm:ss.S`) + NTP 網路校時**
   - 設定好目標時間後，按下懸浮窗上的 **`⏰待命`**，所有準星會自動轉為半透明並開啟 **100% 觸控穿透 (`FLAG_NOT_TOUCHABLE`)**，完全不阻擋點擊或手動滑動。
   - 時間一到，系統立即按照 `#1 → #2 → #3` 順序自動完成所有點擊！
4. **立即測試與緊急停止**
   - 懸浮控制面板提供 **`▶️測試`** 按鈕，可立即實測整套點擊順序與位置是否準確。
   - 點擊過程中隨時可按 **`⏹️急停`** 立即中斷。
